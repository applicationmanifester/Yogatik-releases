Everything the web app does — plus your machine

The desktop build is the same fast, private assistant, extended with two capabilities the browser can't offer.

🖥️

Local Ollama models

Point at a running Ollama daemon and chat with Llama, Qwen, Mistral, DeepSeek and more — fully offline, no API key, nothing sent to any cloud.

📂

Local-file agent

Grant one folder and the agent can read, search, create and edit files inside it — refactors, summaries, batch renames — Cowork-style, scoped and safe.

🔎

Live web research

Metasearch across multiple engines with parallel page reads and cited sources, right inside the conversation.

🧠

On-device models & vision

Run small LLMs and vision models on your GPU via WebGPU. Private by default, works offline after first load.

🛠️

65+ built-in tools

Code execution, image & video generation, OCR, PDF Q&A, diagrams, charts, translation, TTS and much more.

🔒

Private by design

Conversations and keys live in your browser/device. Bring your own free API key; no backend holds your data.

Why run Yogatik on your desktop

A zero-backend AI workspace that lives on your machine. Install once — the app auto-updates itself from there.

⚡

Native performance

A lightweight Electron shell wrapping the full web app. Launches from your Start menu, runs offline, and keeps a window state, tray icon and native notifications.

🔑

Your keys, your data

Bring your own API key (Groq, OpenRouter, OpenAI) or run fully local with Ollama. Keys and conversations stay on your device — Yogatik never proxies your prompts or holds your data.

🔄

Auto-updating

New versions install themselves silently in the background via the built-in updater, so you're always on the latest build without redownloading.

📁

Scoped file access

Grant a single folder and the agent reads, edits and organises files inside it — path-escape guarded, nothing outside the folder is ever touched.

🧩

Skills & workflows

Save reusable prompt skills, chain multi-step workflows with variables, and connect MCP servers — all the power features from the web app included.

🎙️

Live voice & vision

Talk face-to-face with on-device speech, share your camera or screen, and generate images, video and narration — right on your GPU.

1

Download & install

Click Download for Windows above, then run Yogatik-Setup.exe and pick where to install — takes under a minute.

2

Add a model

Enter a free API key in Settings, or install Ollama and pick Ollama (local) to run entirely offline.

3

Grant a folder (optional)

Point the agent at a working folder to unlock local file reading and editing. Everything else works without it.
