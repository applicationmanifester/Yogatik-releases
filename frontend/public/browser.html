Frequently Asked Questions

Common questions about Yogatik Browser standalone.

How does Yogatik Browser differ from the Yogatik Desktop App?

Yogatik Desktop (/platforms) is the full AI assistant workspace with local Ollama models, file editing, and 177 developer tools. Yogatik Browser (/browser) is a dedicated, ultra-fast standalone web browser built with native AdShield, Reader Mode, and privacy-first browsing for daily web use.

Does Yogatik Browser collect my browsing history or search queries?

No. Yogatik Browser has zero telemetry, no user trackers, and no remote surveillance. Your bookmarks, browsing history, and scratchpad notes live strictly inside your local machine profile.

How does AdShield work?

AdShield intercepts network requests at the Electron protocol layer before they load into the DOM, completely neutralizing known ad networks, trackers, and cryptominers without slowing down page rendering.

Is Yogatik Browser free to use?

Yes, 100% free and open-source. There are no subscriptions, paywalls, or hidden limitations for browsing the web with Yogatik Browser.
