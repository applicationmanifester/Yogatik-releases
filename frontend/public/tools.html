Every tool, and what it is for

The assistant has 177 tools available. You never call them by name — the model decides which to use, your browser runs it, and the result appears as a card in the conversation. Almost all of them are free and keyless; the handful that need a key say so. Tools marked desktop need the desktop app, because a web page is not permitted to touch your filesystem or run commands.

How tool calling works here

The model is shown a ranked, capped list of tools relevant to what you asked. It replies with a call, the browser executes it locally, and the result is fed back for the next step — repeating until the model has what it needs to answer. Models that cannot do native function calling fall back to a text protocol automatically, so they keep their tools instead of losing them.
