FAQ

Questions people actually ask

Short answers. Where something is a real limitation, it says so.

Cost and accounts

Is Yogatik free?

The app is free and there is no subscription. What you may pay for is the model: bring a free key (Groq's free tier is generous), a paid key if you prefer frontier models, or run a local model through Ollama and pay nothing at all.

Do I need an account?

No. Signing in is optional and does exactly one thing: it syncs your encrypted API keys between your devices. Conversations are never uploaded.

Why do I need my own API key?

Because there is no server in the middle. Your browser calls the provider directly, which is what makes the app free and private — but it also means the request has to be authenticated as you.

Privacy

Where do my conversations go?

Into IndexedDB in your browser, on your device. There is no application backend to send them to. Your messages do go to whichever model provider you choose — that is unavoidable for any AI assistant — and their handling is governed by that provider's policy.

How is my API key stored?

In your browser's local database. If you sign in, it is encrypted before syncing, using a key derived from your account. In the desktop app it is additionally sealed by the operating system's own credential store. Full detail is on the privacy page.

Can you read my chats?

No. There is nowhere for them to arrive.

Using it

Does it work offline?

The interface, your history and any on-device model do. Cloud models and web-search tools obviously need a connection. Installed as a PWA, it opens offline like a normal app.

Can it read my files?

In the browser, only files you drop into the chat. In the desktop app you can grant one folder, and the assistant can read and edit files inside it — scoped to that folder, per chat, with approval prompts before anything is written.

Which model should I use?

Start with auto-pick: it measures several models and chooses the fastest that responds properly. Models in the 7–15 B range tend to be the sweet spot for tool use; very small models often accept a tool call and then fumble it.

Can I run it on my phone?

Yes — open the site and use “Add to Home Screen”. It installs as a PWA. There is no separate mobile app.

Limitations

Why can't it get a YouTube transcript?

Because a browser cannot fetch it. YouTube blocks the datacenter IPs that public CORS relays run on, and every documented workaround has been measured and fails. The tool returns the video's metadata and tells the model to say so — if you paste or upload a transcript, everything else works normally.

Why did a scheduled task not run?

Scheduled tasks need the desktop app. A browser tab cannot keep a timer alive once it is closed, so the web build cannot honestly offer this.

A model stopped working. Why?

Providers retire model names without notice. Yogatik detects the provider's error, drops the dead model and clears the selection — use auto-pick to land on a current one.
